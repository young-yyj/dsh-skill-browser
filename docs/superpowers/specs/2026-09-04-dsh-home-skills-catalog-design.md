# DSH Home Skills Catalog 设计

## 目标

技能浏览器只展示 DSH Home 的 `skills` 文件夹内容，不再读取当前会话的技能注册表或其他来源。

## 数据来源

运行时通过 DSH Home 路径服务解析 DSH Home，再将 `<DSH_HOME>/skills` 作为唯一根目录。只接受直属子目录中的 `SKILL.md`；不存在目录、无权限目录、无效或过大的文件都返回受限的只读错误状态，不回退到其他技能来源。

## 服务边界

新增一个专职目录扫描服务，负责枚举目录、读取并限制 `SKILL.md` 文本、提取名称和简介、生成分类与详情数据。HTTP 路由只调用该服务；客户端接口和搜索/分类/详情交互保持不变。

## 刷新与安全

监听唯一的 skills 根目录及其直属技能目录变化，使用既有事件流通知浏览器刷新。所有文件路径由服务端根据已枚举的技能名称构造；详情接口不接受任意路径。技能正文继续按纯文本展示，不执行其中的 HTML 或指令。

## 验收

- 不同用户名或 DSH Home 位置下均能解析技能根目录。
- 只返回 `<DSH_HOME>/skills/*/SKILL.md` 对应的技能。
- 添加、修改、删除技能目录后浏览器收到刷新事件。
- 搜索、分类、详情、长度限制与拒绝任意路径读取的测试全部通过。
